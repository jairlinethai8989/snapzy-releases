# SnapZy 1.0.0

First public Windows release.

## Installer Refresh - October 7, 2026

- Updated to .NET 10; .NET is installed separately instead of bundled.
- Setup is 7,933,952 bytes (about 7.94 MB). Existing download links are retained.
- Fixed a Windows PowerShell 5.1 runtime detection error after successful .NET installation. An existing compatible runtime is reused without reinstalling.
- Added English/Thai setup selection, compact EN/TH switching, hotkey success confirmation and complete editor Help icons.
- Corrected post-install launch and shortcut handling, and improved closing multiple editor windows.
- Includes the approved icon A, SnapZy branding and desktop/window capture updates.
- The user confirmed the corrected installation works and approved publication. Version remains 1.0.0.

## Highlights

- Capture a selected area, a window, or a scrolling page.
- Record screen video as MP4 with countdown, recording controls, and preview.
- Annotate images with drawing, shapes, text, blur, highlighting, crop, and numbered markers.
- Combine multiple images into one editable project.
- English is the default language; Thai is available in settings.
- Processing stays on the local PC; screen contents are not uploaded.

## Requirements

- Windows 10 version 2004 or newer, or Windows 11, 64-bit.
- .NET 10 Desktop Runtime 10.0.12 or a compatible newer stable 10.0 patch (x64), Microsoft Edge WebView2 Runtime, and Microsoft Visual C++ 2015-2022 Redistributable (x64).
- FFmpeg is optional and used only for the CPU video-recording fallback.

The installer checks required components. If the required .NET runtime is missing, it asks permission before downloading and installing the official Microsoft runtime. Administrator approval and internet access may be required. Canceling or failing runtime preparation does not replace existing app files. The installer is not code-signed; Windows SmartScreen may display a warning.

## Verification

Both-product native/core, browser and Windows PowerShell installer suites passed. The corrected packaged runtime detector passed on Windows PowerShell 5.1, along with package integrity, icon, language, shortcut and launch checks. The user confirmed successful installation. A clean-machine install/update/uninstall cycle, UAC/restart scenarios and live capture validation on every supported host application have not yet been independently verified.

# SnapZy 1.0.0 (ภาษาไทย)

SnapZy รุ่นสาธารณะรุ่นแรกสำหรับ Windows

## อัปเดตตัวติดตั้ง - 7 ตุลาคม 2026

- ปรับเป็น .NET 10 และแยกติดตั้ง .NET ไม่รวมไว้ในตัวโปรแกรม
- ตัวติดตั้งขนาด 7,933,952 ไบต์ (ประมาณ 7.94 MB) ใช้ลิงก์ดาวน์โหลดเดิม
- แก้การตรวจ .NET ผ่าน PowerShell ของ Windows ที่แจ้งผิดหลังติดตั้งสำเร็จ รุ่นที่รองรับซึ่งมีอยู่แล้วจะใช้ได้โดยไม่ต้องติดตั้งซ้ำ
- เลือกภาษาอังกฤษ/ไทยตอนติดตั้ง สลับภาษาแบบ EN/TH แจ้งผลตั้งค่าคีย์ลัด และแสดงไอคอน Help ครบ
- แก้การเปิดโปรแกรมและสร้างทางลัดหลังติดตั้ง พร้อมปรับการปิดหน้าต่างแก้ไขภาพหลายหน้าต่าง
- รวมไอคอนแบบ A ชื่อ SnapZy และการปรับปรุงจับภาพ Desktop/หน้าต่าง
- ผู้ใช้ยืนยันว่าติดตั้งสำเร็จและอนุมัติเผยแพร่ โดยคงเวอร์ชัน 1.0.0

## ความสามารถเด่น

- จับภาพพื้นที่ หน้าต่าง หรือหน้าจอแบบเลื่อนยาว
- บันทึกวิดีโอ MP4 พร้อมนับถอยหลัง ปุ่มควบคุม และหน้าพรีวิว
- ตกแต่งภาพด้วยการวาด รูปทรง ข้อความ เบลอ ไฮไลต์ ครอป และเลขลำดับ
- รวมหลายภาพเป็นโปรเจกต์เดียวที่แก้ไขต่อได้
- ค่าเริ่มต้นเป็นภาษาอังกฤษ และเลือกภาษาไทยได้ในการตั้งค่า
- ประมวลผลบนเครื่อง ไม่อัปโหลดเนื้อหาหน้าจอ

## ความต้องการของระบบ

- Windows 10 รุ่น 2004 ขึ้นไป หรือ Windows 11 แบบ 64-bit
- .NET 10 Desktop Runtime 10.0.12 หรือแพตช์ 10.0 รุ่นเสถียรที่ใหม่กว่า (x64), Microsoft Edge WebView2 Runtime และ Microsoft Visual C++ 2015-2022 Redistributable (x64)
- FFmpeg เป็นส่วนเสริม ใช้เฉพาะกรณีสำรองการบันทึกวิดีโอด้วย CPU

ตัวติดตั้งจะตรวจสอบส่วนประกอบที่จำเป็น หากยังไม่มี .NET รุ่นที่รองรับ จะถามยืนยันก่อนดาวน์โหลดและติดตั้งจาก Microsoft ซึ่งอาจต้องใช้อินเทอร์เน็ตและสิทธิ์ผู้ดูแลระบบ การยกเลิกหรือติดตั้ง .NET ไม่สำเร็จจะไม่แทนที่ไฟล์โปรแกรมเดิม ตัวติดตั้งยังไม่มีลายเซ็นดิจิทัล Windows SmartScreen อาจแสดงคำเตือน

## การตรวจสอบ

ชุดทดสอบส่วนหลัก หน้าเว็บ และตัวติดตั้งของทั้งสองโปรแกรมผ่านแล้ว รวมถึงการตรวจ .NET จากแพ็กเกจจริงบน Windows PowerShell 5.1 ความครบถ้วนของแพ็กเกจ ไอคอน ภาษา ทางลัด และการเปิดโปรแกรม ผู้ใช้ยืนยันว่าติดตั้งสำเร็จแล้ว ยังไม่ได้ทดสอบวงจรติดตั้ง/อัปเดต/ถอนการติดตั้งบนเครื่องสะอาด กรณี UAC/ต้องรีสตาร์ต และการจับภาพจริงบนทุกโปรแกรมเป้าหมายครบทั้งหมด
