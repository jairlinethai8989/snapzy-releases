# Snapzy 1.0.0

First public Windows release.

## Highlights

- Capture a selected area, a window, or a scrolling page.
- Record screen video as MP4 with countdown, recording controls, and preview.
- Annotate images with drawing, shapes, text, blur, highlighting, crop, and numbered markers.
- Combine multiple images into one editable project.
- English is the default language; Thai is available in settings.
- Processing stays on the local PC; screen contents are not uploaded.

## Requirements

- Windows 10 version 2004 or newer, or Windows 11, 64-bit.
- .NET 8 Desktop Runtime, Microsoft Edge WebView2 Runtime, and Microsoft Visual C++ 2015-2022 Redistributable (x64).
- FFmpeg is optional and used only for the CPU video-recording fallback.

The installer checks required components and provides guidance if any are missing. The installer is not code-signed; Windows SmartScreen may display a warning.

## Verification

Automated build, product-profile, localization, installer-option, and application test suites passed for this package. A clean-machine install/update/uninstall cycle and live capture validation on every supported host application have not yet been independently verified.

# Snapzy 1.0.0 (ภาษาไทย)

Snapzy รุ่นสาธารณะรุ่นแรกสำหรับ Windows

## ความสามารถเด่น

- จับภาพพื้นที่ หน้าต่าง หรือหน้าจอแบบเลื่อนยาว
- บันทึกวิดีโอ MP4 พร้อมนับถอยหลัง ปุ่มควบคุม และหน้าพรีวิว
- ตกแต่งภาพด้วยการวาด รูปทรง ข้อความ เบลอ ไฮไลต์ ครอป และเลขลำดับ
- รวมหลายภาพเป็นโปรเจกต์เดียวที่แก้ไขต่อได้
- ค่าเริ่มต้นเป็นภาษาอังกฤษ และเลือกภาษาไทยได้ในการตั้งค่า
- ประมวลผลบนเครื่อง ไม่อัปโหลดเนื้อหาหน้าจอ

## ความต้องการของระบบ

- Windows 10 รุ่น 2004 ขึ้นไป หรือ Windows 11 แบบ 64-bit
- .NET 8 Desktop Runtime, Microsoft Edge WebView2 Runtime และ Microsoft Visual C++ 2015-2022 Redistributable (x64)
- FFmpeg เป็นส่วนเสริม ใช้เฉพาะกรณีสำรองการบันทึกวิดีโอด้วย CPU

ตัวติดตั้งจะตรวจสอบส่วนประกอบที่จำเป็นและแนะนำเมื่อพบว่ายังขาด ตัวติดตั้งยังไม่มีลายเซ็นดิจิทัล Windows SmartScreen อาจแสดงคำเตือน

## การตรวจสอบ

ชุดทดสอบ build, product profile, localization, ตัวเลือกการติดตั้ง และ application tests ผ่านแล้ว แต่ยังไม่ได้ทดสอบวงจรติดตั้ง/อัปเดต/ถอนการติดตั้งบนเครื่องสะอาด และยังไม่ได้ยืนยันการจับภาพจริงบนทุกโปรแกรมเป้าหมาย
