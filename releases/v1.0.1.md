# SnapZy 1.0.1

Released October 8, 2026 / เผยแพร่ 8 ตุลาคม 2026

## English

### Highlights

- Added local OCR for the whole image or a selected region.
- Added editable plain-text and tab-separated table output before copying.
- Added Thai + English recognition with optional verified Tesseract model files, downloaded only after user consent.
- Fixed artificial spaces inserted between Thai character fragments.
- Redesigned the bilingual OCR window with clear read, copy, busy, empty, and error states.
- Updated the editor Scan Text icon, help coverage, version information, and bundled third-party notices.

OCR images remain on the PC. English can use Windows OCR when available. The optional language-model download does not upload the image.

## ภาษาไทย

### รายการสำคัญ

- เพิ่ม OCR บนเครื่องสำหรับอ่านทั้งภาพหรือเฉพาะพื้นที่ที่เลือก
- ตรวจแก้ผลลัพธ์แบบข้อความหรือตารางคั่นด้วยแท็บก่อนคัดลอกได้
- รองรับภาษาไทยและอังกฤษด้วยโมเดล Tesseract ที่ตรวจสอบแล้ว โดยดาวน์โหลดเมื่อผู้ใช้ยอมรับเท่านั้น
- แก้ปัญหาแทรกช่องว่างผิดระหว่างตัวอักษรภาษาไทย
- ปรับหน้าต่าง OCR สองภาษา พร้อมสถานะอ่าน คัดลอก กำลังทำงาน ไม่พบข้อความ และข้อผิดพลาดที่ชัดเจน
- อัปเดตไอคอนอ่านข้อความ Help เลขเวอร์ชัน และประกาศลิขสิทธิ์ส่วนประกอบภายนอก

ภาพที่นำมาอ่านยังอยู่ในเครื่อง ภาษาอังกฤษสามารถใช้ Windows OCR เมื่อพร้อมใช้งาน และการดาวน์โหลดโมเดลเสริมจะไม่ส่งภาพไปด้วย
